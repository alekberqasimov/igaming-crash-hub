igaming-crash-hub

Create repository.

2) Bu ZIP-i kompüterdə Extract All et.

3) Açılmış qovluğun İÇİNDƏKİ bütün fayl və qovluqları yeni repo-nun ROOT hissəsinə upload et.

hub.example.json
README.md
UPLOAD_STEP_BY_STEP_AZ.txt
.nojekyll
robots.txt

4) Commit changes.

5) GitHub-da Actions tabına keç.

"Migrate games into IGAMING CRASH HUB" workflow-u avtomatik başlamalıdır.

Yaşıl ✓ olana qədər gözlə.

Workflow bitəndən sonra games/ qovluğunda bunlar yaranacaq:

camel-rush/
goal-rush/
penalty/

6) Əgər workflow git push zamanı permission xətası verərsə:

Settings
→ Actions
→ General
→ Workflow permissions
→ Read and write permissions
→ Save

Sonra:
Actions
→ Migrate games into IGAMING CRASH HUB
→ Run workflow

7) Sonra GitHub Pages:

Settings
→ Pages
→ Source: Deploy from a branch
→ Branch: main
→ Folder: /(root)
→ Save
