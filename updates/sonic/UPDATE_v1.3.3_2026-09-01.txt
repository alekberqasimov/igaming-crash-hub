IGAMING CRASH HUB — SONIC ROCKET RUSH
UPDATE VERSION: v1.3.3
DATE: 2026-09-01
STATUS: CANONICAL ROUND ID + HISTORY REPAIR

ROOT CAUSES FOUND
1. Player engine world.id was held only in page memory and restarted from 1 after refresh/reload.
2. P2P persistent history used roundId as its unique key, so restarted #1/#2/... entries overwrote older rounds with the same IDs.
3. v1.3 history validation accepted any finite numeric bust, including invalid 0.00 values.

FIXES
- Adds persistent canonical Sonic room sequence: igch.sonic.roundseq.v133.
- Round IDs now continue forward across refresh/reload instead of restarting at 1.
- P2P leader owns the canonical sequence in shared room mode.
- Solo mode also uses the persistent sequence.
- History accepts only multipliers >= 1.00x.
- Existing invalid 0.xx / 0.00 history entries are removed during repair.
- Existing valid history is retained and normalized, not blindly cleared.
- Legacy sonicrush_round_history_v26 data can be migrated when current P2P history is empty.
- Up to 250 canonical completed rounds are retained.
- Peers exchange their latest sequence and history to prevent sequence rollback after joins/rejoins.
- Incoming round/timeline/history data is validated before use.
