STATUS: CANONICAL ROOM CONFIG SYNC

PURPOSE
Admin SAVE is the source of truth for Sonic runtime configuration across connected SONIC-GLOBAL peers.

BEHAVIOR
- Admin continues using human percentage input: 7 = 7% margin, RTP = 93%.
- Native Admin SAVE persists sonicrush_config_v2 and increments configVersion.
- v1.3.5 stamps the saved config with roomConfigUpdatedAt and roomConfigSource=ADMIN.
- Admin joins the same SONIC-GLOBAL P2P room and broadcasts the saved config.
- Player View joins the config channel automatically through player-hub-link-v221.js.
- Connected peers compare roomConfigUpdatedAt first, then configVersion.
- A newer canonical config replaces the local Sonic config.
- The existing safe config reload layer applies the received config at a safe round boundary rather than interrupting an active local bet.
- Peers send their latest canonical config to newly joined peers.
- A custom Admin SAVE is never overwritten by the 7%/93% code default merely because the page reloads.

PRIORITY
1. Latest Admin SAVE / canonical room config.
2. Previously stored custom config.
3. Default 7% margin / 93% RTP only when no newer custom room config exists.
